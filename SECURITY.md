# Security Policy

This tool processes everything locally and has no server component.

To report a vulnerability (for example an XSS or a CSP bypass), open a GitHub Issue titled `[security]` with the steps to reproduce. Do not include real passwords or personal data in reports.

سياسة الأمان: الأداة تعمل محليًا ولا تحتوي خادمًا. للإبلاغ عن ثغرة افتح Issue بعنوان `[security]` مع خطوات التكرار، ودون إرفاق كلمات مرور حقيقية أو بيانات شخصية.
